# Builder source references

These `.psyexp` files preserve the prior Builder structure for future maintenance. They are not the deployed task entry points and do not yet contain every current allocation, validation, instruction, and five-block code change present in the generated Python files.

For study operation, run the root-level `.py` files directly. Do not open/save these files or regenerate the root-level Python scripts with a different PsychoPy version. Before a future Builder regeneration, port the deployed custom-code changes into a copy of the appropriate `.psyexp`, use the lab-approved PsychoPy version, and compare the resulting Python carefully.
